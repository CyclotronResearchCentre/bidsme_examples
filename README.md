# 🛠️ GIGA-CRC Human Imaging: BIDSme Demonstration Examples

This repository contains **example demonstrations** of the **BIDSme** tools developed at the [GIGA-CRC Human Imaging](https://www.gigacrc.uliege.be/cms/c_4212477/fr/gigacrc) (University of Liège). These tools are designed to facilitate the **standardization, organization, and analysis** of neuroimaging data using the **Brain Imaging Data Structure (BIDS)** format.

---

## 📌 **What is BIDS?**
The **Brain Imaging Data Structure (BIDS)** is a standardized format for organizing and describing neuroimaging datasets. It promotes:
- ✅ **Reproducibility** – Consistent structure across studies.
- ✅ **Interoperability** – Compatible with a wide range of analysis tools.
- ✅ **Transparency** – Clear metadata and file naming conventions.
- ✅ **Automation** – Easier integration with pipelines and workflows.

For more details, check out the [BIDS Specification](https://bids-specification.readthedocs.io/en/stable/index.html) and validate your datasets using the [BIDS Validator](https://bids.neuroimaging.io/tools/validator.html).

## 🔧 **BIDSme Tools**
### **BIDSificator: BIDSme**
- **Purpose**: Convert and organize neuroimaging data into BIDS-compliant datasets.
- **GitHub Repository**: [CyclotronResearchCentre/bidsme](https://github.com/CyclotronResearchCentre/bidsme.git)
- **Publication**: [10.21105/joss.05575](https://doi.org/10.21105/joss.05575)

### **Containerization**
- **Purpose**: Deploy BIDSme in containerized environments for reproducibility and ease of use.
- **GitHub Repository**: [CyclotronResearchCentre/BIDSme_containerisation](https://github.com/CyclotronResearchCentre/BIDSme_containerisation.git)
- **Preprint**: [10.48550/arXiv.2606.09144](https://doi.org/10.48550/arXiv.2606.09144)

## 📂 **Repository Contents**
This repository provides **example datasets and scripts** to demonstrate how to use **BIDSme** for:
- Converting raw neuroimaging data to BIDS format.
- Validating BIDS datasets.
- Integrating BIDS datasets into analysis pipelines.

## 🚀 **Getting Started**
1. Clone this repository to explore the examples.
2. Refer to the **BIDSme** repositories for detailed documentation and usage instructions.
3. Use the [BIDS Validator](https://bids.neuroimaging.io/tools/validator.html) to ensure your datasets comply with the BIDS standard.
